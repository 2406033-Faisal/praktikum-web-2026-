## 📚 Catatan Praktikum

### 🔹 Modul 1 — Instalasi dan Konfigurasi Tools

Pada modul pertama, dilakukan persiapan lingkungan pengembangan web dengan beberapa kegiatan berikut:

- 📝 Instalasi dan verifikasi Visual Studio Code.
- 🟢 Instalasi dan verifikasi Node.js.
- 🗄️ Instalasi dan konfigurasi Laragon.
- 🔧 Instalasi dan konfigurasi Git.
- 🐬 Pengujian layanan MySQL Laragon pada port `3306`.
- ⚙️ Konfigurasi identitas Git global untuk kebutuhan version control.

### 🔹 Modul 2 — Struktur Konten dan Semantik HTML

- Mempelajari struktur dasar dokumen HTML.
- Menggunakan elemen semantik seperti `header`, `nav`, `main`, `section`, `article`, dan `footer`.
- Membuat halaman portofolio mahasiswa.
- Membuat halaman formulir kontak.
- Mengelola perubahan proyek menggunakan Git dan GitHub.

### 🔹 Modul 3 — Styling dan Tata Letak dengan CSS

- Menerapkan CSS untuk mempercantik tampilan halaman HTML.
- Mengatur warna, tipografi, jarak, dan tata letak.
- Menerapkan efek hover pada navigasi dan tombol.
- Membuat tampilan responsif untuk perangkat laptop dan ponsel.
- Melakukan commit dan push perubahan ke GitHub.
